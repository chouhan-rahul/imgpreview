# 🔐 Security Policy

The security of **Img Preview** and its users is important to us. We appreciate responsible security research and encourage anyone who discovers a vulnerability to report it privately.

## 📦 Supported Versions

Security updates are provided for the latest published release of Img Preview.

| Version | Supported |
| :--- | :---: |
| 0.1.x | ✅ |
| Below 0.1.0 | ❌ |

> ⚠️ Security fixes are generally provided through updated releases. Users are encouraged to keep the extension updated to the latest version.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in **Img Preview**, please do not disclose it publicly or open a public GitHub issue.

Instead, report it privately through [GitHub Security Advisories](https://github.com/chouhan-rahul/imgpreview/security/advisories/new).

Please include the following information in your report:

- **Description:** A clear explanation of the vulnerability.
- **Reproduction Steps:** Steps or a minimal code example to reproduce the issue.
- **Impact:** Potential security risks and affected functionality.
- **Affected Versions:** The versions you believe are impacted.
- **Suggested Fix:** If available, any recommendations for resolving the issue.

## ⏱️ Response & Resolution

- We aim to acknowledge vulnerability reports within 48 hours.
- Reports will be reviewed and investigated as promptly as possible.
- Confirmed vulnerabilities will be addressed based on their severity and impact.
- Security fixes will be included in an appropriate updated release.
- Reporters will be kept informed of relevant progress where possible.

## 🤝 Responsible Disclosure

Please allow the maintainer reasonable time to investigate and address reported vulnerabilities before sharing technical details publicly.

We appreciate your help in keeping Img Preview safe and secure.

Thank you for helping protect our users! ❤️
